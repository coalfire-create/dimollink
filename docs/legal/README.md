## 앱이 실제로 다루는 것(약관/방침 작성 근거)

- **수집 개인정보**: 휴대폰번호(로그인 식별자), 이름/상호, 사업자등록번호(업체), 연락처,
  현장/업체 좌표(선택), 결제정보(PortOne 위탁), 요청·정산 내역.
- **인증**: 휴대폰 OTP(SMS 발송사 위탁).
- **제3자 처리위탁**:
  - PortOne(결제·정산·지급대행·세금계산서)
  - 환경부 올바로(전자인계서·회원검증)
  - SMS 발송사(인증코드)
  - 카카오 로컬(주소→좌표 지오코딩)
  - S3 호환 스토리지(현장 사진)
- **위치정보**: 작업 진행 중(IN_PROGRESS) 실시간 위치 공유(업체→요청자). 위치정보법 대상.

# 앱스토어/플레이 등록 · 심사 준비

Expo(RN) 앱을 iOS App Store / Google Play 에 제출하기 위한 메타데이터·심사 준비 체크리스트.

## 빌드/제출

- Expo EAS 빌드 권장: `eas build -p ios`, `eas build -p android` → `eas submit`.
- 앱 서명: iOS 인증서/프로비저닝(Apple Developer 계정), Android 키스토어(EAS 관리 가능).
- 번들 ID/패키지명, 버전/빌드번호 확정.
- 웹 빌드(정적)는 `npm run build -w @dimol/mobile`(expo export --platform web) → Vercel.

## 등록 정보(초안)

- **앱 이름**: 디몰링크
- **부제/한 줄**: 철거·폐기물 처리 매칭 — 올바로 전자인계서까지 한 번에
- **설명**: 소비자·철거업체·운반업체·처리장을 잇는 매칭 플랫폼. 요청 등록→업체 매칭→
  선결제→정산까지, 환경부 올바로 연동으로 전자인계서 신고를 자동화합니다. (파일럿: 양평·
  건설폐기물)
- **키워드**: 철거, 폐기물, 운반, 처리장, 올바로, 전자인계서, 매칭, 정산
- **카테고리**: 비즈니스 / 유틸리티
- **스크린샷**: 온보딩, 요청 등록, 매칭·견적 비교, 결제, 내 정보 (기기별 규격 준수)
- **연령 등급**: 대상 확인(결제 포함).

## 심사 대비(자주 지적되는 항목)

- **개인정보/위치**: 개인정보처리방침 URL, 위치 사용 목적 문구(iOS `NSLocationWhenInUseUsageDescription`),
  Android 위치 권한 근거. 앱 내 위치 동의 UI.
- **결제**: 실물 용역(오프라인 서비스) 결제이므로 앱 내 결제(IAP) 대상이 아님을 명확히
  (디지털 콘텐츠 아님). 결제대행(PortOne) 사용 근거.
- **계정 삭제**: 앱 내 회원 탈퇴/계정 삭제 경로 제공(스토어 요구).
- **로그인**: 휴대폰 OTP. Apple '소셜 로그인 시 Apple 로그인 필수' 규정은 소셜 로그인 미사용
  시 비해당.
- **접근성**: 고령 사용자 대상 — 글자 18px+/버튼 48px+ 준수(디자인 기준 이미 반영).

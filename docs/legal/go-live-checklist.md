# 상용화 체크리스트 (비코드 · 계약·신청·온보딩)

코드 외에 상용 오픈에 필요한 비즈니스·법무·운영 항목. 리드타임이 긴 것부터 병행 진행.

## 1. 사업자·계약 (리드타임 김 — 최우선)

- [ ] 법인/개인 사업자 등록(폐기물·중개 관련 업종 확인).
- [ ] **포트원(PortOne) 가맹 계약·심사** — 결제/정산/지급대행/전자세금계산서. 정산 대상 업체
      등록(운반업체·처리장·철거업체) 및 지급대행 약정.
- [ ] **환경부 올바로 API 신청·승인** — 회원검증·전자인계서 연동 규격 수령(현재 코드는
      가정값이므로 실제 규격으로 교체 필요).
- [ ] SMS 발송사 계약(발신번호 사전등록), 카카오 개발자(로컬 API) 키 발급.

## 2. 파일럿 실물 확보 (Phase 0)

- [ ] 운반업체 5곳, 처리장 3곳 실제 온보딩(계약·정산계좌·사업자번호·올바로 회원).
- [ ] 철거업체 파트너 확보.
- [ ] 양평 지역·건설폐기물 범위 확정 및 시범 거래 파트너.

## 3. 법무 (변호사 검토)

- [ ] 이용약관 / 개인정보처리방침 / 위치기반서비스 약관 확정(초안: `docs/legal/`).
- [ ] 위치정보사업/위치기반서비스사업 신고 필요 여부 확인(방통위 기준).
- [ ] 전자상거래·전자금융 관련 필수 고지, 통신판매업 신고 여부.
- [ ] 개인정보 보호책임자 지정, 처리위탁 계약서(수탁사별).

## 4. 운영 준비

- [ ] 관리자(백오피스) 운영 계정·토큰(`ADMIN_TOKEN`) 발급·보관, 승인/분쟁 대응 담당 지정.
- [ ] 지급대행 스케줄러(정산일 D+1) 운영 트리거 연결(`/api/payments/payouts`, 관리자 토큰).
- [ ] 올바로 전자인계서 재시도 큐/실패 모니터링 운영 절차.
- [ ] 고객지원 채널(문의·환불·분쟁), 정산/환불 SOP.

## 5. 인프라·검증 (코드는 준비됨 — `docs/infra/`)

- [ ] 관리형 PostgreSQL + Redis 프로비저닝, 시크릿 주입, TLS/WAF/CDN.
- [ ] 모니터링/알림·백업 크론 적용.
- [ ] 실기기 테스트(iOS/Android) + 고령 접근성 확인, 부하·보안 점검.
- [ ] 샌드박스→운영 전환 검증(PortOne test→live, 올바로 sandbox→production) — 사람 diff 검토.

## 6. 스토어 심사

- [ ] EAS 빌드·제출, 개인정보/위치 문구, 계정 삭제 경로(상세: `app-store-listing.md`).

## 0. 큰 그림 — 무엇이 크리티컬 패스인가

승인 대기가 긴 것부터 **가장 먼저 병렬로** 걸어둔다. 실제 개발은 이미 상당 부분 완료(백엔드 실 DB 검증, 모바일 번들 빌드)라 **병목은 코드가 아니라 행정·승인**이다.

| 순서 | 항목 | 예상 소요(추정)※확인 | 선행조건 |
|---|---|---|---|
| 1 | 법인 설립(선택 시) | 1~2주 | 상호·자본금·주소 |
| 1 | 사업자등록 | 즉시~3일 | (법인이면)등기 완료 |
| 1 | 폐기물 관련 인허가/지위 검토 | 수주~수개월(불확실) | 사업 형태 확정 |
| 2 | 올바로 API 연계 승인 | **수주~수개월**(가장 긺) | 사업자·폐기물 지위 |
| 2 | 포트원 가맹+지급대행 심사 | 1~4주 | 사업자·계좌·통신판매신고 |
| 2 | Apple D-U-N-S 발급 | 1~2주 | 법인 정보 |
| 3 | 소셜 로그인(카카오 비즈앱/네이버 검수) | 1~7일 | 개인정보처리방침 URL |
| 3 | 스토어 심사 | 며칠~2주 | 빌드·방침 URL |

**결론: 올바로·포트원·D-U-N-S·법인설립을 1주차에 동시 착수.** 나머지는 그 대기시간에 병행.

## 1. 개인사업자 vs 법인 — 어떤 걸로 낼까

### 결론: **법인은 "무조건"이 아니다. 개인사업자로 시작 가능하며, 본격화 전 법인 전환을 권장.**

법인은 *강제가 아니라 유리한 선택*일 뿐이다. 아래 두 가지를 **웹으로 직접 확인한 결과**, 개인사업자로도 시작에 법적 걸림돌이 없다:

1. **포트원(PortOne) 지급대행 — 개인사업자 가능(확인됨).** 포트원 파트너정산 도입 조건은 "사업자등록을 완료한 **법인 또는 개인사업자**"이며, 포트원은 개인·개인사업자·법인 등 모든 유형 파트너에게 정산 가능하다고 명시한다(일반 PG사와의 차별점). → 결제·정산 때문에 법인이 강제되지는 않는다. (출처: PortOne 헬프센터)
2. **폐기물 중개/알선 — 신고제(확인됨).** 폐기물 수집·운반·중개·알선업은 처리시설 설치 "허가"와 달리 **신고제**로 운영된다. 플랫폼의 합법성은 **직접 수거·운반·처리를 수행하는지 vs 순수 정보중개인지**에 달려 있다. 우리처럼 **직접 폐기물을 취급하지 않고 배출자↔허가업체를 연결만** 하면 처리업 "허가" 대상이 아닐 수 있으나, **중개/알선 신고 요부는 관할 지자체·행정사 확인 필수**. (출처: 국가법령정보/찾기쉬운 생활법령)

> 즉 **개인사업자든 법인이든 위 두 서비스는 이용 가능**. 형태 선택은 "규제 강제"가 아니라 **세금·책임·신뢰·투자** 관점의 판단이다.

**그래도 법인이 유리한 경우**: ① 결제·정산 대금이 큰 **B2B 고액 플랫폼**, ② 대표 **유한책임**(폐기물·자금 리스크 차단), ③ **투자유치·확장** 계획, ④ PG·관공서·업체 심사에서 대외신뢰. → 이 중 다수에 해당하면 처음부터 법인.

**개인으로 시작이 나은 경우**: 양평 소수 건 **개념검증(PoC)** 위주, 초기 비용·회계부담 최소화. → 개인사업자로 빠르게 시작 후, 거래액·정산 규모가 커지거나 투자 시점에 법인 전환.

### 비교

| 항목 | 개인사업자 | 법인(주식회사) |
|---|---|---|
| 설립 절차/비용 | 간단, 거의 무료(즉시) | 등기 필요, 등록면허세·공증 등 수십만원~ ※확인 |
| 대외 신뢰(PG·업체·관공서 심사) | 낮음 | **높음**(가맹·연계 심사 유리) |
| 대표 책임 | 무한책임 | **유한책임**(자본금 한도) |
| 세금 | 종합소득세(누진 최대 45%대) | 법인세(과표구간, 통상 낮음)+대표 급여 | ※세무사 확인 |
| 자금 분리/투자유치 | 어려움 | **용이**(주식·투자·정산자금 분리) |
| 회계 부담 | 낮음 | 복식부기·법인결산·법인세 신고(세무사 필요) |
| PG 지급대행·전자금융 계약 | 제약 가능 | **선호됨** |

### 결정 가이드 (한눈에)
| 상황 | 추천 |
|---|---|
| 양평 소수 건 개념검증(PoC) | **개인사업자**로 빠르게 시작 |
| 결제·정산 규모 큼 / 투자·확장 / 리스크 차단 | **법인** |
| 잘 모르겠다 | 개인으로 시작 → 본격화 전 **법인 전환** |

- ⚠️ **핵심**: 포트원 **지급대행**을 쓰면 플랫폼이 직접 정산자금을 보유하지 않아 **전자금융업 등록 부담을 낮추는 구조**다(그래서 CLAUDE.md가 포트원 지급대행을 전제). 다만 **선결제 자금 흐름의 전자금융거래법 해당 여부는 변호사 확인 필수**.
- ⚠️ 형태보다 먼저 확인할 것: **① 포트원이 요구하는 서류·심사 조건(개인/법인별)**, **② 폐기물 중개/알선 신고 요부(관할 지자체)**. 이 답에 따라 형태가 자연스럽게 정해진다.

### 업종(업태·종목) 등록
사업자등록 시 아래를 포함(정확한 코드는 세무서/홈택스 확인 ※확인):
- 전자상거래(통신판매) / 응용소프트웨어 개발·공급(플랫폼)
- **폐기물 수집·운반·처리 "중개/알선"** — ⚠️ 이 부분이 규제 민감. 단순 정보중개인지, 폐기물처리 신고/허가 대상인지 **행정사·관할 지자체 폐기물팀 확인 필수**. 올바로 연계·전자인계서 발행 주체 요건과도 직결.

## 2. 법인 설립 (법인으로 갈 경우)

**소요: 1~2주 / 비용: 수십만원~(자본금 별도) ※확인**

1. **상호·목적·자본금·주소·임원 확정** — 목적에 "폐기물 수집운반·처리 중개업, 전자상거래업, 소프트웨어 개발업" 등 포함.
2. **잔고증명**(자본금 납입) → 은행 법인 예정 계좌.
3. **정관 작성·공증**(자본금 10억 미만은 공증 생략 가능 ※확인).
4. **설립등기 신청**(관할 등기소 또는 온라인 등기, 법무사 대행 가능) → **등록면허세·지방교육세** 납부.
5. **법인등기부등본·법인인감** 발급.
6. **사업자등록**(홈택스/세무서, 등기 후) → 사업자등록증 수령.
7. **법인 통장 개설**(등기부·인감·사업자등록증 지참).
- 팁: 법무사 대행 시 3~7일 단축 가능(대행료 별도 ※확인).

## 4. 올바로 API 연계 (⏱ 최장 — 1주차에 즉시 착수)

**소요: 수주~수개월(승인·규격협의 포함, 가장 김) ※확인 / 비용: 통상 무료(인증서 비용 별도) ※확인**

### 사전 요건
- 사업자등록 완료, **폐기물 관련 지위/인허가 정리**(2·1항). 올바로는 폐기물 배출/운반/처리 주체·연계사업자 요건이 있으므로, 플랫폼이 어떤 자격으로 연계하는지 사전 정의 필요.

### 절차
1. **allbaro.or.kr 사업자 회원가입** → 사업자번호 인증.
2. **고객지원/콜센터 문의** — "Open API(연계서비스) 사용" 신청 방법·양식·요건 확인(사이트 구조가 자주 바뀌므로 콜센터가 가장 확실). 운영기관: 한국환경공단.
3. **연계 사용 신청서 + 서비스 개요서 제출** — 용도(회원검증·전자인계서 자동발행·실적 반영), 예상 거래량, 시스템 구성, 보안 대책.
4. **심사·협의** — 기관과 연동 범위·규격 협의(이 단계가 길다).
5. **승인 후 수령**: API 인증키, **전자인계서용 공인인증서**, **연동 규격서(WSDL/REST 명세)**, **샌드박스(테스트) 계정**.

### 개발 반영 (수령 후)
- `apps/api/src/allbaro/client.ts`의 엔드포인트/필드를 **규격서대로 교체**(현재 `/member/verify`·회원유형 코드 등은 임시 가정).
- `.env`: `ALLBARO_API_BASE_URL`·`ALLBARO_API_KEY`·`ALLBARO_CERT_PATH`, `ALLBARO_ENV=sandbox`.
- 샌드박스로 회원검증·전자인계서·재시도 큐 검증 → **사람 diff 검토(CLAUDE.md 의무)** → `ALLBARO_ENV=production`+`ALLBARO_ALLOW_PRODUCTION=true`.

## 5. 포트원(PortOne) 결제·정산 가맹 (⏱ 1주차 착수)

**소요: 1~4주(PG·카드사 심사 포함) ※확인 / 비용: 결제 수수료(거래액 %)+지급대행/세금계산서 수수료 ※확인**

1. **admin.portone.io 가입 → 상점(Store) 생성.**
2. **사업자 심사 서류 제출**: 사업자등록증, 대표자 신분증, **정산 계좌(통장사본)**, 통신판매업 신고증, (필요 시)홈페이지/앱 심사자료.
3. **결제수단 신청** — **가상계좌(계좌이체) 우선**(B2B 고액·카드수수료 절감), **카드 병행**. 각 PG/카드사 심사 통과 필요.
4. **지급대행(마켓플레이스) 신청** — 셀러(운반/처리)별 정산·수수료 자동차감. **전자세금계산서** 발행 기능 신청.
5. **웹훅 등록** — 결제/정산 결과 통지받을 서버 URL(운영 도메인 필요).
6. **키 수령·설정**: 테스트/라이브 `PORTONE_STORE_ID`·`PORTONE_API_SECRET`.
7. **검증**: `PORTONE_ENV=test`로 선결제→정산→환불→세금계산서 전 과정 → **사람 diff 검토** → `PORTONE_ENV=live`+`PORTONE_ALLOW_LIVE=true`.
- ⚠️ **셀러 등록 정보** 사전 확보: 업체별 사업자번호·정산계좌·상호(지급대행에 필수).

## 6. Apple D-U-N-S + 스토어 (⏱ D-U-N-S는 1주차 착수)

**D-U-N-S 소요: 1~2주(무료) ※확인** — 법인 앱 배포에 필수.
1. Apple의 D-U-N-S 조회/신청 페이지에서 법인 정보로 신청(이미 있으면 조회만).
2. **Apple Developer Program** 가입(연 $99 ※확인) — 법인 명의(D-U-N-S 필요).
3. **Google Play Console** 개발자 등록(1회 $25 ※확인) + 신원·사업자 확인.
4. 앱 등록: 번들ID `com.dimollink`, 아이콘/스크린샷/설명, **개인정보처리방침 URL(필수)**, 데이터 안전(Play)·앱 개인정보(App Store) 문항, 연령등급.
5. 빌드: `npm install` → `npx expo install expo-camera` → `npx expo prebuild`(app.json↔네이티브 Hermes 정합) → **EAS Build**(`eas build`) → 심사 제출(며칠~2주 ※확인).

## 7. 소셜 로그인 (대기시간에 병행 — 1~7일)

각 콘솔 앱 생성 → **Redirect URI `dimollink://oauth` 등록 + 이메일 필수 동의** → `.env` 반영.
- **카카오**: 이메일 수집은 **비즈앱 전환**(사업자 정보) 필요 — 검수 소요 ※확인. `KAKAO_CLIENT_ID/SECRET/REDIRECT_URI`, `KAKAO_REST_API_KEY`(지오코딩 공용).
- **구글**: OAuth 동의화면에 **개인정보처리방침 URL** 필수. `GOOGLE_CLIENT_ID/SECRET/REDIRECT_URI`.
- **네이버**: 이메일 제공 필수+검수. `NAVER_CLIENT_ID/SECRET/REDIRECT_URI`.
- ⚠️ 소셜·구글·스토어 모두 **개인정보처리방침 URL이 선행**이므로 법무 문서를 일찍 만들어 웹에 올려둘 것.

## 8. 법무 문서 (일찍 착수 — 다른 신청의 선행)

## 12. 착수 순서 요약 (1페이지)

**1주차(동시 착수)**: 법인설립/사업자 → 폐기물 지위 법률검토 → **올바로 연계 신청** → **포트원 가맹** → **Apple D-U-N-S** → **법무 문서 작성 시작**.
**대기 중 병행**: 소셜 앱 등록, 인프라 셋업(DB/서버/도메인/시크릿), 업체 입점 영업, 개인정보처리방침 웹 게시.
**키·승인 수령 후**: 샌드박스/테스트 연동 → **사람 diff 검토** → 모바일 화면·prebuild·EAS 빌드 → 스토어 심사 → 파일럿 리허설(양평 실제 1~2건) → 운영 전환 플래그(`ALLBARO_ALLOW_PRODUCTION`/`PORTONE_ALLOW_LIVE`).

> 개발 완료도: 백엔드 코어·데이터 계층은 **실 PostgreSQL 왕복 검증 완료**, 모바일 **번들 빌드 성공**. 남은 병목은 위 행정·승인·연동·심사다.

# 디몰링크 상용화 — 필요 서류·정보 총정리

> 상대처별로 준비해야 할 서류(문서)와 정보(데이터)를 모두 정리. 파일럿(양평·건설폐기물) 기준.
> 대부분 **사업자등록·대표자 신원·계좌**가 공통 선행. 실제 요구 목록은 각 기관 최신 안내로 재확인.

---

## 0. 공통 기본 서류 (거의 모든 신청에 필요)

- [ ] 사업자등록증(폐기물 중개/플랫폼업 등 업태·종목 포함)
- [ ] 법인등기부등본(법인) / 대표자 신분증
- [ ] 법인인감증명서·사용인감계(계약·가맹 시)
- [ ] 통신판매업 신고증(전자상거래 해당 시)
- [ ] 대표 정산·수신 은행 계좌(통장 사본), 예금주=사업자명 일치
- [ ] 회사 대표 이메일·연락처·주소, 담당자 정보
- [ ] 서비스 도메인, 앱/서비스명(디몰링크), 로고(스토어·PG 심사용)

## 1. 올바로시스템 API `[정부]`

**서류/신청**
- [ ] 올바로 사업자 회원가입(환경부 한국환경공단)
- [ ] 폐기물처리 신고/허가 관련 증빙(중개 플랫폼 지위 확인 서류)
- [ ] Open API(연계) 사용 신청서 + 서비스 개요서(용도·트래픽·연동 범위)
- [ ] 공인인증서(전자인계서 전송용) 발급

**수령·설정 정보** → `.env`
- [ ] `ALLBARO_API_BASE_URL`(샌드박스/운영 각각)
- [ ] `ALLBARO_API_KEY`, 인증서 경로(`ALLBARO_CERT_PATH`)
- [ ] **연동 규격서**(엔드포인트·요청/응답 필드) — 코드의 임시 가정을 실제로 교체
- [ ] 회원유형 코드표(배출/운반/처리 매핑), 의무신고 기준(건설폐기물 5톤)

**연동에 쓰는 사용자 데이터**
- 회원사 사업자등록번호(가입 시 입력), 전자인계서 당사자(배출·운반·처리) 사업자번호·폐기물 품목·중량

## 2. 포트원(PortOne) 결제·정산·세금계산서 `[PG]`

**서류/가맹**
- [ ] PortOne 가입 + 사업자 심사 서류(사업자등록증·대표자·계좌)
- [ ] 카드사/은행 심사(가상계좌·카드 결제수단), 정산 계좌 등록
- [ ] 지급대행(마켓플레이스, 셀러별 정산) 사용 신청
- [ ] 전자세금계산서 발행 사용 신청(공인인증/사업자 정보)
- [ ] 에스크로/선불 전자지급 관련 필요 시 등록(전자금융업 해당 여부 확인)

**수령·설정 정보** → `.env`
- [ ] `PORTONE_STORE_ID`, `PORTONE_API_SECRET`(테스트·라이브)
- [ ] 웹훅(결제/정산 통지) 수신 URL 등록
- [ ] 정산 주기 설정(D+1), 수수료 차감 규칙

**셀러(업체) 등록 정보** (지급대행)
- 업체별 사업자등록번호·정산 계좌·상호·연락처

## 3. 소셜 로그인 앱 등록 `[OAuth]`

각 개발자 콘솔에서 앱 생성 후 **redirect URI `dimollink://oauth` 등록 + 이메일 필수 동의**.

- [ ] **카카오**(developers.kakao.com): 앱 생성, REST/네이티브 키, 카카오 로그인 활성화, 동의항목(이메일·닉네임), 비즈앱 전환(이메일 수집 시) → `KAKAO_CLIENT_ID/SECRET/REDIRECT_URI`, `KAKAO_REST_API_KEY`(지오코딩 공용 가능)
- [ ] **구글**(console.cloud.google.com): OAuth 동의화면 구성(앱명·로고·개인정보처리방침 URL·범위 email/profile), OAuth 클라이언트 ID → `GOOGLE_CLIENT_ID/SECRET/REDIRECT_URI`
- [ ] **네이버**(developers.naver.com): 네이버 로그인 앱 등록, 제공정보 이메일 필수, 검수 신청 → `NAVER_CLIENT_ID/SECRET/REDIRECT_URI`

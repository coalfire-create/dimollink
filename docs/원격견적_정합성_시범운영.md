# 원격 견적 정합성 시범 운영 (20~30곳)

목적: "원격 견적이 방문 견적과 거의 같다"를 실제 현장 숫자로 확인한다.
방문 견적끼리도 업체마다 10~20% 차이가 나므로, 기준은 **0% 차이가 아니라 "방문 업체끼리의 차이보다 크지 않은가"** 다.

계산·판정 정의: `packages/shared/src/estimate-parity.ts` / 관리자 화면 **관리자 → 견적 정합성** 탭.

## 1. 현장 모집

- 목표 **25곳**(최소 20곳 — 20곳 미만이면 화면이 판정을 보류한다).
- 구조(철근콘크리트·조적·목조)와 규모(소형 주택~중형 상가)가 한쪽으로 몰리지 않게 섞는다. 한 구조가 절반을 넘지 않게 한다.
- 지하 구조물·석면 의심 현장도 일부러 넣는다. 원격이 약한 현장을 빼면 결과가 좋게 나와도 믿을 수 없다.
- 소비자에게는 "견적 비교 시범 참여"로 안내하고 동의를 받는다(방문 2곳 + 원격 1곳을 받는다는 점).

## 2. 현장당 견적 수집

| 구분 | 수 | 방법 |
|---|---|---|
| 원격 | 1곳 이상 | 원격 실사 자료(촬영 패키지·3D 스캔·필요 시 영상통화)만 보고 **확정 금액** |
| 방문 | **2곳 이상** | 직접 현장을 보고 **확정 금액** |

- 방문이 2곳 이상이어야 "방문 업체끼리의 차이"를 잴 수 있다. 1곳이면 그 현장은 ±10% 비교만 된다.
- 모두 **같은 범위**(철거 범위·폐기물 처리 포함 여부·부가세 포함 여부)로 받는다. 범위가 다르면 비교가 무의미하다 — 견적서를 받으면 범위부터 맞춘다.
- 개산(범위)이 아니라 **확정 금액**만 기록한다.

## 3. 블라인드

- 방문 업체는 **원격 금액을 보지 못하게** 한다. 원격 견적은 방문이 모두 끝난 뒤 공개하거나, 방문 업체에 아예 알리지 않는다.
- 방문 업체끼리도 서로의 금액을 모르게 한다(플랫폼의 밀봉 규칙과 같다).
- 원격 견적자는 방문 금액을 모른 채 낸다. 순서가 바뀌면 그 현장은 표본에서 뺀다.

## 4. 기록

- 플랫폼 안에서 진행한 건: 견적의 실사 방식(원격/방문)이 기록돼 있으면 관리자 화면 **"플랫폼 견적에서 다시 계산"** 버튼으로 자동 표본이 생긴다.
- 플랫폼 밖 견적이 섞이면: **시범 현장 입력** 폼에 직원이 넣는다(요청 id 또는 `시범-01 양평 단독주택` 같은 현장 이름, 원격 금액, 방문 금액 2개 이상, 구조, 연면적).
- 같은 현장이 자동·직원 입력 둘 다 있으면 **직원 입력을 기준**으로 계산한다.
- 견적서 사본(PDF·사진)은 공유 드라이브 `시범운영/현장번호/` 에 보관한다. 화면에는 금액만 넣는다(사업자번호 등 개인정보는 넣지 않는다).

## 5. 철거 후 실적 톤

- 철거가 끝나면 올바로 처리 실적(또는 처리장 계량표)의 **실제 처리 톤**을 표본의 "실적 톤 입력"에 넣는다.
- 플랫폼 견적이 취소·변경돼 근거가 사라져도, 실적 톤·메모가 들어간 표본은 지우지 않고 "계산 제외"로 남긴다. 견적이 다시 생기면 자동으로 계산에 돌아온다.
- 이 값은 금액 판정에는 쓰지 않고, 플랫폼의 **물량 추정(톤) 오차**를 따로 보여준다. 장기적으로 추정 원단위 보정에 쓴다.
- 현재 올바로 반입·계량 톤은 서버에 자동 저장되지 않으므로 직원이 입력한다.

## 6. 보고서 읽는 법

| 항목 | 뜻 |
|---|---|
| 차이 | 원격 금액(여러 개면 중앙값) ÷ 방문 금액 중앙값 − 1. **−면 원격이 쌈** |
| 차이 중앙값 | 현장별 차이(부호 무시)의 가운데 값 |
| 현장 80%의 차이 상한 | 80% 현장이 이 값 이하(최근접 순위) |
| ±10% 안 비율 | 차이가 ±10% 이내인 현장의 비율 |
| 방문 업체끼리 차이 | (방문 최고가 − 최저가) ÷ 방문 중앙값, 방문 2곳 이상인 현장만 |
| 치우침 | 부호 있는 차이의 중앙값이 ±3%를 넘으면 "원격이 대체로 낮다/높다" |

## 7. 판정 규칙

- **표본 부족**: 비교한 현장 < 20곳. 숫자만 보고 결론 내지 않는다.
- **합격(PASS)**: ① ±10% 안 현장이 80% 이상 **그리고** ② 차이 중앙값 ≤ 방문 업체끼리 차이 중앙값.
- **불합격(FAIL)**: 위 중 하나라도 미달.

결정:

- 합격 → 원격 견적을 정식 기능으로 열고, 현장 화면에 "방문 견적과의 차이 중앙값 ○%" 를 근거로 쓴다.
- 불합격 → 목표 밖 현장을 모아 원인을 분류한다(촬영 누락·지하 구조물·석면·범위 불일치). 촬영 가이드를 고친 뒤 10곳을 더 받아 다시 본다.
- 치우침이 "원격이 낮다"면 원격에서 놓치는 항목(지하·부속 구조물 등)을 촬영 체크리스트에 추가한다. "높다"면 원격 업체가 불확실성을 금액에 얹고 있는 것이니 실사 자료를 보강한다.

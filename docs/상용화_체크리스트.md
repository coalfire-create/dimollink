# 디몰링크 상용화 체크리스트

> ⚠️ **이 문서는 2026-07-22 기준이라 낡았다. 현재 상태는 `docs/실운영_체크리스트.md` 를 본다.**
> 그 사이에 끝난 것: 관리자 role 체계(계정 role + 비상 토큰), 업체(공급자) 화면,
> 취소/환불 화면, 올바로 재시도 큐 영속화, PostgreSQL 운영, 현장 사진 스토리지,
> 솔라피 SMS, 디몰비전(건축물대장·사진분석). 서비스 범위도 양평 파일럿 → **전국구**로 바뀌었다.
> 남은 큰 덩어리: 포트원 가맹 심사 통과 → **지급대행·전자세금계산서 실연동**(현재 모의 응답,
> live 에서는 차단), 올바로 운영 승인, 소셜 로그인 운영 키, 법무·행정 신고, 스토어 제출.

> 파일럿(양평·건설폐기물) 출시까지 필요한 전체 항목. 실제 코드 경로·환경변수 기준.
> `[코드]`=개발로 완결 / `[크레덴셜]`=외부 키·승인 필요 / `[사업]`=사람·행정 / `[인프라]` / `[법무]`.
> 우선순위: 🔴필수(출시 차단) · 🟡중요 · 🟢개선.

## 0. 현재까지 완료·검증된 것 (기준선)

- 인증: 이메일/비번(JWT HS256·scrypt), 소셜 로그인(카카오/구글/네이버), 로그인 레이트리밋
- 올바로 회원검증 연동(샌드박스): 업체 미회원 거부·배출자 제외·장애 백스톱
- 매칭 라이프사이클: 요청→후보(거리순)→확정→선결제→배차→작업→완료→정산, 취소/환불(단계별 위약금)
- 업체 온보딩/승인(관리자), 업체 잡 흐름(오너십), 알림(주입식), 지오코딩(주입식+폴백)
- 결제 견적·정산(수수료 7%) 연결, PortOne 클라이언트(테스트모드)
- **PostgreSQL 저장소 + 마이그레이션 0001~0005 — 실제 PG 왕복 검증 완료**
- 모바일: 소셜 로그인·촬영 가이드·매칭 요청 흐름 UI, **실제 Metro 번들 빌드 성공(585모듈)**
- 백엔드 189개 테스트·typecheck·eslint 통과

## 2. 실 크레덴셜·외부 연동 `[크레덴셜]` 🔴

- [ ] **올바로**: 운영 키·인증서 → `ALLBARO_API_KEY`/`ALLBARO_API_BASE_URL`, 샌드박스 검증 완료 후 `ALLBARO_ENV=production` + `ALLBARO_ALLOW_PRODUCTION=true`
  - 실 규격에 맞춰 엔드포인트/필드 확정(`apps/api/src/allbaro/client.ts`의 `/member/verify` 등은 임시 가정)

- [ ] **PortOne**: 테스트모드 키로 선결제→정산→환불→세금계산서 전 과정 검증 → 운영 전환(`PORTONE_ENV=live` + `PORTONE_ALLOW_LIVE=true`)

현장 사진 올리기

건물 내부를 방마다 여러 장씩, 최대한 많이 올려주세요. 사진이 많을수록 자재 인식과 철거 과정 안내가 정확해집니다. 외부 4방향·지붕재 근접 사진도 함께 넣으면 더 좋습니다.

현장 주소

주소를 넣으면 건축물대장(공공데이터)에서 주구조·연면적·사용승인일을 확인해 분석의 기준으로 씁니다. 사진 판독보다 신뢰도가 높은 확정 정보입니다.

지도를 움직여 현장 위치를 정확히 찝어 주세요.

부가 정보 (선택)

건물 한 바퀴 영상 올리기

사진이 아니라 영상입니다. 건물 주위를 45~60초 동안 한 바퀴 걸으면서 계속 찍어주세요. 사진 여러 장으로는 부피가 나오지 않습니다 — 연속된 화면이어야 카메라가 어디 있었는지 풀 수 있습니다.

  1. 건물이 화면에 다 들어오는 거리까지 물러섭니다.
  2. 카메라를 건물 쪽으로 향한 채 천천히 한 바퀴 걷습니다.
  3. 멈추지 말고 계속 찍습니다. 끊으면 이어붙일 수 없습니다.
  4. 출발점으로 돌아와 2~3초 더 찍고 끝냅니다.

‘지금 촬영’은 화면에 너무 빠릅니다 / 초점이 흐립니다 같은 안내를 실시간으로 띄워, 다 찍고 나서 실패를 알게 되는 일을 막아줍니다.

무엇을 찍었나요

한 바퀴 도는 동안 걸은 걸음 수를 넣으면 실제 치수 오차가 줄어듭니다 (±25% → ±18%). 휴대폰 만보기 값을 그대로 넣어도 됩니다.

현장 주소를 사진 분석 화면에서 먼저 확인해 두면 건축물대장 연면적으로 크기 기준을 잡아 정확도가 올라갑니다.
